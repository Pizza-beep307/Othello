# Reversi (Othello) - Java

Simple implementation of the Reversi board game (console-based) developed during my first year of CS degree (BUT Informatique).

## 🎮 Features
* **Game Modes:**
  * **Solo:** Play against the computer, 2 type of bots (basic AI)
  * **Duo:** Hotseat mode for 2 players.
* **Customizable Board:** Supports board sizes from 4x4 to 16x16.
* **Assist:** Displays valid moves for the current player.
* **Console UI:** Simple text-based interface ('O' vs 'X').

## 🛠️ Tech Stack
* **Language:** Java (No external libraries used).
* **Concepts:** Arrays, Loops, Methods.
